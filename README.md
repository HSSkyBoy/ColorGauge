# O-Pulse

O-Pulse is a read-only KernelSU WebUI module for Oplus devices. It displays
charging power, battery information, thermal zones and the newest vendor
battery CSV values.

The runtime has one state contract:

- `bin/chg_daemon` is the primary C++ collector.
- `collector.sh` is a compatibility fallback when the binary is unavailable.
- Both collectors atomically write `run/state.json`.
- `webroot/` reads only that state file through the KernelSU Shell bridge.

The collector follows the original monitoring script: it polls every three
seconds while USB is online, reads the battery/USB voltage and current nodes,
calculates power, capacity, health, ETA and peak/average statistics, discovers
common Oplus thermal zones, and reads the newest battery CSV row.

## Install

Use the ZIP generated by GitHub Actions or a Release, then install it through
KernelSU and reboot. The CI ZIP contains the compiled arm64-v8a
`bin/chg_daemon`; a source checkout ZIP does not.

## Build locally

```powershell
$ndk = "$env:LOCALAPPDATA\Android\Sdk\ndk\29.0.13113456"
cmake -S native -B native/build/android-arm64 `
  -DCMAKE_TOOLCHAIN_FILE="$ndk\build\cmake\android.toolchain.cmake" `
  -DANDROID_ABI=arm64-v8a `
  -DANDROID_PLATFORM=android-26 `
  -DCMAKE_BUILD_TYPE=Release
cmake --build native/build/android-arm64 --parallel
```

Put the resulting binary at `bin/chg_daemon` in the module package. If it is
absent, `service.sh` starts the Shell fallback and records the selected path
in `run/collector.log`.

## Compatibility

The module is mainly for viewing status and does not change charging settings.
Vendor nodes differ between OPPO, OnePlus and realme models; unavailable
fields are reported as `N/A` or `null` instead of taking the whole collector
offline.
